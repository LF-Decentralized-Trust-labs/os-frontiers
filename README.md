# Open Source Frontiers (OSF) Lab

> **Linux Foundation Decentralized Trust · Stage 0 research candidate**
>
> A **Web3** framework for who decides, how money goes out, and how money comes back. The same framework also applies to Web2 foundations, companies, and public funders.

The Open Source Frontiers Lab publishes a three-part design for funding the maintenance of open-source infrastructure.

Ecosystems can spend on maintenance for years and still have no path for the value of that infrastructure to come back, so funding stays a one-way grant.

```text
        dOSPO                         who decides
       /     \
     OMF     ORF                      how money goes out / how money comes back
       \     /
     treasury                         governed allocations
```

No [hard gate](GLOSSARY.md#hard-gates) is marked passed. A score from the evaluator is not a pass.
