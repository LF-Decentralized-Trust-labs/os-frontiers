## 1. Overview

This directory contains illustrative **smart contract sketches** for the Open Replenishment Framework (ORF) Enterprise SLA Vault:

1. **EVM Solidity Sketch (`solidity/ORFSlaVault.sol`)**: Illustrates reciprocal fee-split routing between enterprise SLA purchasers and maintenance retainer pools.
2. **Cardano Aiken Validator Sketch (`aiken/validators/orf_sla_vault.ak`)**: Illustrates UTxO-based SLA fee escrow and operator signature authorization logic.

> ⚠️ **CAUTION**: These contracts are unaudited reference sketches intended for research and feasibility modeling. They must undergo formal security auditing before deployment in any production environment.
