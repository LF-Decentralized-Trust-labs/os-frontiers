# Use cases

Stage 0 research notes sit next to the submission template. They are research candidates. No Hard Gate is passed. A figure in a note is a publisher figure or a site counter only where that note says so.

Ecosystem precedent profiles stay in [`docs/precedents/`](../docs/precedents/). These files do not replace them and do not change `dospo/`, `omf/`, `orf/`, or the evaluator.
