## 1. Primary Function & Capabilities
OSO indexes GitHub repositories, smart contract activity, and npm/PyPI dependencies to provide verifiable metrics for open-source impact.

## 2. Role in dOSPO / OMF / ORF Suite
- **OMF Audit & Impact**: Supplies verifiable metrics for maintainer retainers, developer retention, and project health checks.
- **RetroFunding Support**: Serves as the official impact analytics provider for Optimism RetroFunding rounds.
