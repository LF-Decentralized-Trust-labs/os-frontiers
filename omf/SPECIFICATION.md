# OMF: Open Maintenance Framework Specification

> **HOW SPEND: Operational Architecture for Sustained Infrastructure Maintenance**  
> *Companion to the dOSPO Governance Framework and the Open Replenishment Framework (ORF)*

---

## 1. Executive Summary

The **Open Maintenance Framework (OMF)** resolves the operational question in open-source sustainability: **How do governance mandates and treasury capital become structured, sustainable maintenance programs?**

Rather than relying on one-off, friction-heavy grant proposals or episodic hackathons, the OMF manages an ecosystem's core infrastructure as a managed portfolio. It translates community-approved mandates into predictable operational programs.

---

## 2. Core Program Pillars

```
+---------------------------------------------------------------------------------+
|                                 OMF PORTFOLIO                                   |
|                                                                                 |
|  +-------------------+  +-------------------+  +-----------------------------+  |
|  | Maintainer        |  | Contributor       |  | Tooling Stewardship &       |  |
|  | Retainers         |  | Pathways          |  | Lifecycle-Aligned Funding   |  |
|  | * Recurring stips |  | * Onboarding      |  | * Incubation -> Core        |  |
|  | * Defined scope   |  | * Mentorship      |  | * Maintenance SLAs          |  |
|  | * Security duties |  | * Grant ladders   |  | * Tooling maintenance       |  |
|  +-------------------+  +-------------------+  +-----------------------------+  |
+---------------------------------------------------------------------------------+
```

1. **Maintainer Retainers**: Predictable, recurring compensation for core maintainers with clear operational boundaries, security availability commitments, and public performance reporting.
2. **Contributor Pathways**: Structured onboarding, mentorship programs, and progressive contribution ladders to prevent maintainer burnout and expand ecosystem capability.
3. **Tooling Stewardship**: Systematic support for critical shared dependencies, developer tooling, documentation, and security auditing.
4. **Lifecycle-Aligned Funding**: Funding mechanisms matched to project maturity stages (Incubation, Growth, Sustained, Sunset).

---

## 3. Maintainer Autonomy Safeguard

Funding provided under OMF programs supports project maintenance and operational capability; **it never purchases authority over project roadmaps or technical decision-making**. Unpaid community contribution pathways remain open and celebrated.

---

## 4. Key Deliverables & Artifacts

- **Program Charters**: Bounded operational plans for retainers and stewardship programs.
- **Maintainer Retainer Templates**: Standard agreements defining retainer scope, reporting requirements, and compensation structures.
- **OMF Health Metrics**: Track maintainer retention, response latency, patch throughput, and dependency health.
