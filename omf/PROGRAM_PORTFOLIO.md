## 1. Executive Summary & Architecture

The **Open Maintenance Framework (OMF)** defines *how money goes out*. OMF is the execution engine for deploying approved treasury capital into open-source software maintenance, vulnerability remediation, contributor incubation, and security resilience.

OMF consists of five core programs, each supported by real-world Web3 production precedents:

## 2. Exhaustive Program Specifications

### 2.1 Program 1: Maintainer Retainers
- **Objective**: Provide continuous, predictable monthly stipends to core developers, eliminating grant dependency and salary compression.
- **Web3 Precedents**: **Protocol Guild** ($7.2M raised from 6,202 donors in 2025, 187 members in 2026 across 10+ core Ethereum clients) and **Cardano POSM** (Maintainer Retainer 6-developer pre-pilot).
- **Operational Mechanics**: Operates via on-chain time-weighted tenure formulas or Superfluid CFA per-second token streams. Developers undergo a 30-day evaluation window before entering 12-month retainers.

### 2.2 Program 2: Code Bounties & Bug Bounties
- **Objective**: Reward discrete technical contributions, feature implementations, and vulnerability disclosures.
- **Web3 Precedent**: **Cardano POSM Bug Bounty Program** ($300,000 first-year pool fully utilized by July 23, 2026; $1k–$20k payout tiers; 7–14-day classification SLAs).
- **Operational Mechanics**: Triage is executed by a technical security council, with payouts processed via Merit Terminal (USDC on Base) or smart contract escrow within 30 days of validation.

### 2.3 Program 3: Contributor Pathways & Progression Ladders
- **Objective**: Institutionalize developer onboarding, converting new enrollees into trusted maintainers.
- **Web3 Precedents**: **Polkadot Technical Fellowship** (Ranks 0 to 9 with peer-reviewed rank progression) and **Andamio Protocol** (Cardano Plutus course validators & tokenized credentials).
- **Progression Ranks**: *Rank 0 Candidate* $\rightarrow$ *Rank 1–2 Regular Contributor* $\rightarrow$ *Rank 3–5 Trusted Developer* $\rightarrow$ *Rank 6–9 Core Architect*.

### 2.4 Program 4: Resilience & Security Auditing
- **Objective**: Perform proactive security audits, technical debt refactoring, and dependency bus-factor interventions.
- **Web3 Precedents**: **Sovereign Tech Fund** (€20M+ invested across 60+ foundational projects) and **Deep Funding** ($220K 2025 challenge mapping 34 seed repos and 5,000+ dependencies).
- **Operational Mechanics**: Utilizes Open Source Observer (OSO) and GrimoireLab CHAOSS metrics to identify critical single-maintainer dependencies and fund emergency security audits.

### 2.5 Program 5: Incubation Program (Frontier Research Contractors)
- **Objective**: Transition grant-dependent Digital Public Goods (DPGs) into market-tested commercial maintenance providers.
- **Web3 Precedent**: **Project Odin (EF Funding Coordination & Renaissance Philanthropy)** (`blog.ethereum.org/2026/02/27/project-odin`).
- **3-Stage Progression**: *Stage 1 Discovery/Mapping (Months 1–3)* $\rightarrow$ *Stage 2 Validation/Planning (Months 4–6)* $\rightarrow$ *Stage 3 Execution/De-risking (Months 7–12)*.
