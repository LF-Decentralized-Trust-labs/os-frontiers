# Open Maintenance Framework (OMF)

> **HOW DEPLOY: Operational Maintenance, Retainers, Contributor Pathways & Tooling Stewardship**  
> *Author: Christian Taylor · Open Source Frontiers Lab · LF Decentralized Trust*  
> *Companion to the dOSPO Framework and the Open Replenishment Framework (ORF)*

---

## 1. Executive Summary

The **Open Maintenance Framework (OMF)** resolves the operational deployment question in treasury-funded ecosystems: **How is capital deployed to sustain open-source infrastructure as a predictable, high-health portfolio?**

Traditional grant systems treat open source as a series of episodic, one-off project applications. This creates maintainer grant fatigue, high administrative friction, and severe maintenance neglect for critical underlying dependencies. 

The OMF replaces one-off grants with a **5-Requirement Compliance Bar** that transforms open-source maintenance into a professional, portfolio-managed operation.

---

## 2. The 5-Requirement OMF Compliance Bar

To qualify for OMF maintenance deployment, a program or repository must meet five falsifiable criteria:

1. **Structured Maintainer Retainers**: Predictable 12-month stipends streamed continuously (via Superfluid, Sablier, or fiat contracts) rather than friction-heavy one-off grant applications.
2. **Maintainer Autonomy Protections**: Funding supports technical maintenance capacity; **it never purchases technical roadmap authority, feature vetoes, or code review control**.
3. **Dependency Graph Coverage**: Automated auditing (via Open Source Observer / Drips) mapping upstream and downstream dependencies to prevent single-point-of-failure (SPOF) collapse.
4. **Structured Contributor Pathways**: Defined onboarding ladders, documentation, and mentorship to prevent maintainer burnout and lower Bus Factor risks.
5. **Independent Performance Reporting**: Quarterly disclosures (`OMF/QUARTERLY_REPORT_TEMPLATE.md`) detailing release cadence, issue triage latency, and security patch responsiveness.

---

## 3. Core OMF Program Types

- **Maintainer Retainer Program**: 12-month recurring stipends for core repository maintainers.
- **Contributor Pathway Program**: Mentorship grants and contributor onboarding stipends.
- **Tooling Stewardship Program**: Portfolio funding for shared developer tooling, indexers, and compilers.
- **Lifecycle-Aligned Funding**: Staged capital allocations matched to project maturity (Incubating -> Active -> LTS Maintenance).
