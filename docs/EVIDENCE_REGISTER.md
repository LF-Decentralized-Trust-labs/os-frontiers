## 1. Executive Overview

This document provides a canonical **Primary-Source Evidence Register** indexing every external precedent, operational analog, primary source URL, verified status, and exact maturity classification used throughout the **Open Source Frontiers (OSF)** framework suite (dOSPO · OMF · ORF).

The framework enforces a 3-tier evidence legend for external precedents:
- 🟢 **Live Precedent**: Materially similar mechanism operates in production today.
- 🟡 **Partial Analog**: Components proven in production, but the integrated OSF mechanism requires piloting.
- 🔵 **Research-Stage**: Conceptual financial or governance analog requiring technical, legal, or economic validation.
