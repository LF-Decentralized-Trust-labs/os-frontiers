A community-funded security bounty for Litecoin Core

This project establishes a dedicated pool to reward researchers who identify and responsibly disclose security vulnerabilities in Litecoin Core, including MWEB. Donations support bounties for validated findings, with awards based on severity, potential impact, and available funds.

The goal is to encourage independent security research and help developers address vulnerabilities before they can harm users.

Why this matters

A dedicated bounty fund gives researchers a clear incentive to investigate Litecoin Core and report issues privately so fixes can be coordinated before public disclosure. That work helps protect user funds, preserve consensus integrity, and improve the security and reliability of the Litecoin network.

This benefits users, node operators, miners, exchanges, wallets, and other services that depend on Litecoin Core.

How donations will be used

Funds raised here will be reserved for validated security findings. Awards will be based on:

- Severity of the vulnerability

- Potential impact on users and the network

- Available funds in the bounty pool

Fundraising goal: $100,000

Program status

Program scope, reporting instructions, eligibility requirements, and reward criteria will be published before bounty submissions are accepted. Until then, this page is for funding the pool — not for submitting vulnerability reports.

How to contribute

Donate on this page to help grow the bounty pool. Contributions support responsible disclosure and give maintainers more capacity to review, fix, and coordinate security issues in Litecoin Core and MWEB.

Led by David Burkett, https://github.com/DavidBurkett, a lead contributor to Litecoin Core and MWEB.
