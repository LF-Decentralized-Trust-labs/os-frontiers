# Maintainer Autonomy & Retainer Guide

> **Guaranteeing Technical Independence for Open-Source Maintainers under OMF and ORF**  
> *LF Decentralized Trust · Open Source Frontiers Lab*

---

## Executive Summary for Maintainers

As an open-source maintainer, your primary concerns when accepting treasury or enterprise funding are:
1. *Will accepting money compromise my technical control over the repository?*
2. *Will corporate sponsors force features onto my project roadmap?*
3. *How predictable are retainer stipends compared to friction-heavy grant proposals?*

The **Open Maintenance Framework (OMF)** and **Open Replenishment Framework (ORF)** were specifically designed to protect **maintainer autonomy**.

---

## The Maintainer Autonomy Safeguard

> **Non-Negotiable Rule**: Funding provided under OMF retainers and ORF enterprise SLAs supports project maintenance capacity; **it never purchases authority over technical decision-making, code reviews, or project roadmaps**.

```
+-----------------------------------------------------------------------------------+
|                            MAINTAINER AUTONOMY SAFEGUARD                          |
|                                                                                   |
|  [ Enterprise Client / Treasury ]                                                 |
|               │                                                                   |
|               ▼ (Purchases Support SLA / Grants Retainer)                         |
|   [ OMF Program Operator (under dOSPO Policy Safeguards) ]                         |
|               │                                                                   |
|               ▼ (Provides Monthly Stipend & Retainer Stream)                      |
|    [ Open Source Maintainer ] ───> 100% Autonomous Technical Roadmap Control      |
+-----------------------------------------------------------------------------------+
```

---

## Key Benefits for Maintainers

- **Predictable Stipends**: Monthly recurring retainers streamed on-chain (via Superfluid or Sablier) or paid via standard fiat contracts.
- **No Grant Application Fatigue**: Retainers are structured as ongoing 12-month program charters renewed based on maintenance health—not one-off grant proposals.
- **Universal Security Handling**: Enterprise clients receive patch windows and response commitments, but emergency security intake and bug fixes remain open to the public.
- **Unpaid Contribution Pathways**: Unpaid community contributors can still submit PRs and participate in project governance without barriers.

---

## Maintainer Retainer Charter Checklist
- [ ] Defined monthly retainer stipend amount & payment schedule
- [ ] Agreed security patch availability and PR review SLA
- [ ] Published quarterly maintenance health report
- [ ] Explicit Maintainer Autonomy Safeguard clause signed by funder
