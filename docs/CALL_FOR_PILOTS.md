# Call for pilots

Draft invitation. Nothing in this file has been sent, and no ecosystem has been enrolled. Web3 treasuries are the primary audience. The same invitation can be adapted for a Web2 foundation, a company, or a public funder.

No [hard gate](../GLOSSARY.md#hard-gates) is marked passed. A point score is not a pass. This draft does not name a pilot, a price, or a commitment.

## What a pilot is

A pilot is a public trial of the treasury quickstart: [QUICKSTART_FOR_TREASURIES.md](../QUICKSTART_FOR_TREASURIES.md). It uses the five questions, three starter spending programs, and one replenishment instrument already named there. It is not a new program invented for this page.

The lab does not hold the treasury. [dOSPO](../GLOSSARY.md#dospo) does not hold it either. The ecosystem's own governance decides whether to try any of this.

## What this draft does not do

- It does not sign an ecosystem up.
- It does not promise funding, a retainer, or a launch date.
- It does not add a scored ecosystem. An evidence-free scaffold lives at [evaluator/examples/SECOND_ECOSYSTEM.md](../evaluator/examples/SECOND_ECOSYSTEM.md) so nobody confuses zeros with a measurement.

## How to answer

Reply in public, on a pull request or a discussion, with:

1. The ecosystem's name and a public URL.
2. Which of the three starter programs, or the one replenishment instrument, the ecosystem wants to try.
3. What public records already exist (minutes, receipts, or a charter). Leave out any number that is not in those records.
