## What they do

A GitHub program that runs maintainers through a three-week security sprint and then a 12-month follow-up. Each project gets $10,000 through GitHub Sponsors, paid in stages: $6,000 during the sprint and $2,000 at each of the six- and 12-month check-ins. Projects also get training (threat modeling, secure coding, AI security), office hours with GitHub Security Lab, and Azure credits. Money comes from GitHub, Microsoft and outside funding partners.

## Gaps and cautions

- Outcomes are self-reported by GitHub. CVE counts measure disclosures, not risk reduced.
- Payments go only to maintainers in regions GitHub Sponsors supports, which limits who can join.
- Session totals should not be added to the cumulative figure; the cumulative figure already includes them.
