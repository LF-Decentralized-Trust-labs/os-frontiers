## What they do

The non-profit that maintains the Open Source Definition and approves open source licenses. Its role in sustainability is mostly as a reference point: programs such as the Open Source Pledge use OSI's definition to decide which projects count. It publicly supports the Pledge, is an ecosystem partner of GitHub's Secure Open Source Fund, and co-published the 2026 State of Open Source report. It receives corporate donations itself, for example from Sentry.
