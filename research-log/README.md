# Research log

These files are a working audit trail. They record checks, disagreements, and follow-ups behind the documents in `docs/`, `use-cases/`, and `whitepapers/`. They are not the specification. They do not pass a hard gate. They are not a claim that a program launched.

Local working-copy paths have been rewritten to repository paths. Tool names have been removed from the prose. The filenames are unchanged so a reader can still match a note to an earlier commit.

Nothing in this directory was deleted from the project. The notes were moved here from `docs/chains/`, `docs/surveys/`, and `use-cases/`.
