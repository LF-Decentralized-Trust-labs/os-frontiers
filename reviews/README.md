# Independent reviews

Stage 1 in [VALIDATION.md](../VALIDATION.md) is a recorded review by at least two independent people. This directory is where that record would go. No review is filed here. The lab is still Stage 0.

A review is not a hard gate, and it is not a score. The reviewer does not become a maintainer by being named. Maintainer seats are in [MAINTAINERS.md](../MAINTAINERS.md) and stay empty until someone agrees.

## What a review file contains

Copy the block below to `reviews/YYYY-MM-DD-scope.md` only after the review happened. Leave every blank empty rather than guessing.

```text
# Review

- Date:
- Reviewer:
- Scope (files or sections):
- Disposition (accept, accept with changes, or decline):
- What was checked:
- What was not checked:
```

Do not add a file for a review that did not happen.
